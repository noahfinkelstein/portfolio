title: A plain website
date: 2026-08-28
summary: Why the new version of this site has so little on it.
tags: [meta]
---

The first version of this site had an animated particle field behind my name,
a three-dimensional object that spun when you scrolled, and a headline that
cycled through nine things I supposedly did — full stack development, machine
learning, aerospace engineering, and so on down the list. It looked like every
other personal site, which is to say it looked generated rather than written.
It also took a while to load a page whose entire useful content was my email
address.

So this version has none of that. White background, one serif, one mono, dates
in a column down the left. If you came here to find out what I have worked on,
that is now the first thing on the screen, with nothing in front of it.

I kept the blog because I want somewhere to put things that are too long for a
text message and too small for a paper: a proof I liked, a bug that took three
days, a plot that came out wrong in an interesting way. Whether I actually
write them is a separate question.
